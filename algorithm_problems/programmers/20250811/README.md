### 두번째

## 시간복잡도

* **합 구하기 (2중 for문)**

  * `i` 0 \~ N-1, `j` i+1 \~ N-1
  * 반복 횟수 = N(N-1)/2 ≈ **O(N²)**

* **중복 제거 (unordered\_set 사용)**

  * 평균적으로 삽입 O(1) → 전체 **O(N²)** 안에 포함

* **최종 정렬**

  * 중복 제거 후 남은 값의 개수 = k (최대 N(N-1)/2 ≈ O(N²))
  * 정렬 = **O(k log k)** → 최악 **O(N² log N²) = O(N² log N)**

* **총합**

  * **O(N² + N² log N)** → 빅오 표기에서는 **O(N² log N)**
  * (N이 충분히 크면 정렬이 지배)

## 배운 것

정렬되어 있지 않기 때문에 sort를 해주어야 합니다.
